## 💻 วิธีการเปิดใช้งานระบบ (2 รูปแบบ)

### รูปแบบที่ 1: เปิดใช้งานผ่านเว็บบราวเซอร์ทันที (Local / Standalone)
1. ดับเบิลคลิกเปิดไฟล์ `index.html` บน Google Chrome หรือ Microsoft Edge
2. ระบบจะโหลดรายชื่อครูจาก Google Sheet ให้อัตโนมัติ พร้อมแสดงเวลาปัจจุบันแบบเรียลไทม์
3. สามารถทดสอบลงรับหนังสือ โดยกดปุ่ม **"สร้างเอกสารทดสอบ"** หรือลากไฟล์ PDF / รูปภาพ เข้ามา
4. กดบันทึกข้อมูลเพื่อดูตราปั้มที่ 1 มุมบนขวา
5. ไปที่แท็บ **"รอลงนาม"** เพื่อกด **"เสนอ ผอ."** (ตราปั้ม 2 ซ้ายล่าง) และ **"ความคิดเห็น ผอ."** (ตราปั้ม 3 ขวาล่าง)

### รูปแบบที่ 2: ติดตั้งบน Google Apps Script (Cloud Deployment)
1. ไปที่ [Google Apps Script](https://script.google.com/) แล้วสร้างโปรเจกต์ใหม่
2. คัดลอกโค้ดจากไฟล์ `Code.gs` ไปวางในโปรเจกต์
3. สร้างไฟล์ HTML เพิ่มเติมใน Apps Script โดยนำเนื้อหาจาก `index.html` ไปใส่
4. กด **Deploy (การทำให้ใช้งานได้)** > **New deployment (การทำให้ใช้งานได้รายการใหม่)**
5. เลือกประเภท: **Web app (เว็บแอป)**
   - Execute as: **Me (ฉัน)**
   - Who has access: **Anyone (ทุกคน)**
6. กด Deploy และนำ Web App URL ที่ได้ มากรอกลงในแท็บ **"ตั้งค่าระบบ & GAS"** ของหน้าเว็บ เพื่อเชื่อมต่อแบบ 100% สองทิศทาง

## 📂 โครงสร้างไฟล์ในโฟลเดอร์
- `index.html` - หน้าเว็บหลัก Single Page Application โทนสีน้ำเงิน รองรับมือถือและคอมพิวเตอร์
- `style.css` - สไตล์ชีตระบบราชการโทนสีน้ำเงิน Royal Blue และ Glassmorphism
- `app.js` - ระบบจัดการคลังข้อมูล, ปฏิทิน พ.ศ., การเชื่อมต่อ Google Sheet API, ลายเซ็น
- `stampEngine.js` - เครื่องมือประทับตราความละเอียดสูงด้วย Canvas และ PDF-Lib
- `stampAssets.js` - ข้อมูล Base64 ของตราปั้มทั้ง 3 ป้องกันปัญหา Canvas Taint
- `Code.gs` - สคริปต์เชื่อมต่อ Google Sheet และ Google Drive สำหรับ Google Apps Script
- `ตราปั้มหนังสือรับ.png` - เทมเพลตตราปั้มที่ 1 (โรงเรียนบ้านสันดาบ)
- `ตราปั้มหนังสือรับ 2.png` - เทมเพลตตราปั้มที่ 2 (เรียนผู้อำนวยการโรงเรียนบ้านสันดาบ)
- `ตราปั้มหนังสือรับ 3.png` - เทมเพลตตราปั้มที่ 3 (ความเห็นเสนอผู้บริหาร)
